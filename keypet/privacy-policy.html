KeyPet Privacy Policy

Last updated: September 12, 2026

Short version: KeyPet uses local keyboard input events only to trigger desktop character animations and gameplay counters. KeyPet does not record, store, transmit, upload, or analyze the text you type.

1. About KeyPet

KeyPet: Pixel Pet ("KeyPet", "the game", "we", or "us") is a Windows desktop companion game. Pixel characters react to your local keyboard activity, unlock progress, and in-game actions.

2. Keyboard Input Handling

KeyPet uses Windows keyboard input events while the game is running to trigger character animations and gameplay feedback.

KeyPet does not record, store, transmit, upload, or analyze the actual text you type. KeyPet does not save passwords, messages, form contents, document contents, clipboard data, screenshots, or screen content.

3. What KeyPet Processes Locally

For gameplay purposes, KeyPet may process the following information locally on your device:

  • That a keyboard event occurred while the game is running.
  • Aggregate key event counts used for gameplay progress.
  • Timing information used for character reactions and typing-related gameplay feedback.
  • In-game progress, such as currency balance, unlocked characters, selected characters, and related gameplay settings.

This information is used for local gameplay behavior and save data. It is not used to reconstruct or analyze the text you type.

4. Local Save Data

KeyPet may store local save data on your Windows device, such as gameplay progress, character unlock state, selected characters, and aggregate counters. This data is stored locally so the game can restore your progress.

Local save data does not contain typed text, passwords, document contents, clipboard contents, screenshots, or individual typed words.

5. Network and Steamworks Features

KeyPet does not send keyboard input data or typed text to our servers. If Steamworks features are enabled, the game may use Steam services for functions such as game ownership checks, achievements, cloud saves, or related platform features.

Steam services are provided by Valve and are subject to Steam's own privacy policy and account settings.

6. Third-Party Advertising and Tracking

KeyPet does not use third-party advertising trackers. KeyPet does not sell personal data.

7. Security and Antivirus Notes

Because KeyPet reacts to keyboard events for gameplay, some antivirus or security tools may warn about keyboard hook behavior. This behavior is used for local gameplay feedback only. KeyPet does not record typed content or upload keyboard data.

8. Support Contact

If you contact us for support, we will use the information you provide only to respond to your request and investigate the issue you reported.

Contact: zepar05041@gmail.com

9. Changes to This Policy

We may update this policy when KeyPet changes its features, platform integrations, or data handling practices. The date at the top of this page shows the latest update.

KeyPet 隐私政策

最后更新：2026 年 9 月 12 日

简短说明：KeyPet 仅在本机使用键盘输入事件触发桌面角色动画和游戏计数。KeyPet 不记录、不保存、不传输、不上传、也不分析你输入的具体文本内容。

1. 关于 KeyPet

KeyPet: Pixel Pet（以下简称“KeyPet”或“本游戏”）是一款 Windows 桌面宠物游戏。像素角色会根据你的本机键盘活动、解锁进度和游戏内操作做出反馈。

2. 键盘输入处理

KeyPet 会在游戏运行期间使用 Windows 键盘输入事件，用于触发角色动画和游戏反馈。

KeyPet 不会记录、保存、传输、上传或分析你输入的具体文本内容。KeyPet 不会保存密码、聊天内容、表单内容、文档内容、剪贴板内容、截图或屏幕内容。

3. KeyPet 在本机处理的信息

出于游戏玩法需要，KeyPet 可能会在你的设备本机处理以下信息：

  • 游戏运行期间发生了键盘事件。
  • 用于游戏进度的累计按键事件数量。
  • 用于角色反应和打字反馈的时间信息。
  • 游戏进度，例如货币余额、角色解锁状态、当前角色和相关游戏设置。

这些信息仅用于本机游戏行为和存档，不用于还原或分析你输入的具体文本。

4. 本地存档

KeyPet 可能会在你的 Windows 设备上保存本地存档，例如游戏进度、角色解锁状态、当前角色和累计计数。这样游戏才能恢复你的进度。

本地存档不包含输入文本、密码、文档内容、剪贴板内容、截图或具体输入词句。

5. 网络与 Steamworks 功能

KeyPet 不会把键盘输入数据或输入文本发送到我们的服务器。如果启用了 Steamworks 功能，游戏可能会使用 Steam 服务进行游戏拥有权校验、成就、云存档或相关平台功能。

Steam 服务由 Valve 提供，并受 Steam 自身隐私政策和账号设置约束。

6. 第三方广告和追踪

KeyPet 不使用第三方广告追踪器。KeyPet 不出售个人数据。

7. 安全软件提示

由于 KeyPet 会为了游戏反馈使用键盘事件，部分杀毒软件或安全工具可能会提示键盘钩子相关行为。该行为仅用于本机游戏反馈。KeyPet 不记录输入内容，也不上传键盘数据。
